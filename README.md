# Variability-Based Practice in Sport-Specific Skill Learning

## Overview

This repository contains the data and R code associated with a systematic review and meta-analysis examining the effects of variability-based interventions on sport-specific skill learning.

The repository is intended to support transparency, facilitate the understanding of the data extraction and coding procedures, and enable the reproduction of the analyses reported in the associated publication.

## Repository Contents

The repository will include:

- **Data:** Extracted data used in the systematic review and meta-analysis.
- **Data dictionary:** Definitions of the variables, coding categories, and conventions used in the dataset.
- **R code:** Scripts used to prepare the data, conduct the meta-analyses, and generate the results and figures.
- **Reproducibility instructions:** Information about the software, packages, and steps required to run the analyses.

## Data Structure

The dataset is organised at the comparison and assessment level. Each row represents an extracted dataset for a specific study or experiment, sport-specific skill, comparison between practice conditions, learning outcome, and assessment time.

The dataset includes study identifiers, study references, sport and skill characteristics, learning outcomes, assessment times, practice-regime comparisons, sample sizes, means, and standard deviations for the comparison groups.

The variable `higher_better` indicates whether higher values represent better performance for a given outcome.

A detailed data dictionary will be provided to explain all variables and coding decisions.

## Reproducibility

Instructions for running the R scripts, including the required software and package dependencies, will be provided in this repository.
